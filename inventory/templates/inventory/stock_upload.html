How the import works

Columns: Sr. No. Code Barcode Size Quantity, plus optional Sales Price and Cost Price.

  • Each Barcode becomes one product (the POS scans barcodes).
  • The product name is built as Code — Size (e.g. ME1001 — Small).
  • New products go to the Clothing department with Zero Tax / No Deposit.
  • Price columns are optional. Products without them start at 0.00.
  • If a barcode already exists, the quantity is added to current stock, and prices update only where the sheet has a value.
  • All-or-nothing: if any row is invalid, nothing is saved and every problem is listed.
