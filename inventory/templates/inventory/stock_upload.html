How the import works

  • Each Barcode becomes one product (the POS scans barcodes).
  • The product name is built as Code — Size (e.g. ME1001 — Small).
  • Every product goes to the Clothing department with Zero Tax / No Deposit placeholders.
  • Sales Price / Cost Price columns are optional — include them to set prices during import; products without them start at 0.00.
  • If a barcode already exists, the sheet quantity is added to the current stock, and prices are updated only where the sheet provides a value.
  • All-or-nothing: if any row is invalid (missing barcode, non-numeric quantity or price), nothing is saved and every problem is listed.
